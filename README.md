# 🛒 RiftShop

RiftShop is a modern e-commerce web application designed to provide customers with a simple and responsive online shopping experience.

The application allows users to browse products, place orders, and complete payments through an online ordering workflow.

## 🚀 Features

- 🛍️ Product browsing
- 🛒 Online ordering
- 💳 Payment functionality
- 📦 Customer order history
- 📱 Responsive and mobile-friendly design
- 🎨 Modern and intuitive user interface
- 🔄 Frontend-to-backend communication
- ⚡ Optimised application performance

## 🛠️ Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- Git & GitHub
- Vercel

## 👨‍💻 My Role

I designed and developed the application, implementing responsive layouts, reusable components, shopping functionality, frontend-to-backend communication, ordering workflows, and payment functionality.

I also worked on integrating the application's payment workflow, managed source code using Git/GitHub, and deployed the application using Vercel.
